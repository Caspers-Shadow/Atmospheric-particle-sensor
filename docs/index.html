01

The mission

Make real atmospheric data feel tangible.

The project develops a practical atmospheric sensing artefact around a Raspberry Pi 5, environmental sensors, particulate sensing, local visualisation and remote data logging.

The focus is not laboratory-grade atmospheric analysis. The focus is building an accessible platform that demonstrates the complete journey from a physical environmental change to a recorded, visualised dataset.

06 / Engineering reality

A sensor timeout should not crash the mission.

Read PMS5003→Timeout?→Retry ×3→Flag −1→Keep running

The implementation preserves continuity even when a particulate measurement cannot be obtained, allowing failed reads to be identified later instead of silently disappearing.

08 / What the project demonstrates

A complete sensing pipeline, not just a sensor demo.

01

Integrated acquisition

Multiple sensing components operate through one Raspberry Pi application.

02

Local visualisation

The LCD turns sensor output into immediate physical feedback.

03

Remote collection

Selected measurements can be transmitted to ThingSpeak for later analysis.

04

Automated preparation

Python scripts clean, organise and summarise collected data consistently.

05

Resilience

Handled failures are recorded without forcing the full acquisition loop to stop.

06

Scientific limits

Relative sensor responses are kept distinct from calibrated concentration claims.
